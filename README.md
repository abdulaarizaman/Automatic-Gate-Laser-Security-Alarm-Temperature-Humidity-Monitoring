# Smart Automatic Gate with Theft Protection and Environment Monitoring

A smart Arduino-based security system that automatically opens a gate when a person approaches and provides theft detection along with real-time temperature and humidity monitoring.

This project was developed as part of a **Science Exhibition Project (Class VIII)**.

---

## Project Overview

The **Smart Security Gate System** is designed to improve security and automation using Arduino and sensors.

The system automatically opens a gate when a person approaches and closes it after a short delay. It also includes a **laser-based theft protection system** that triggers an alert if unauthorized entry is detected.

Additionally, the system monitors **temperature and humidity** using a sensor and displays the information on an LCD screen.

This makes the project useful for both **security automation and environmental monitoring**.

---

## Key Features

- Automatic gate opening using **Ultrasonic Sensor**

- **Laser + LDR based theft detection system**
- **Buzzer alarm** for security alerts

## How the System Works

### 1. Automatic Gate Operation
- The **Ultrasonic Sensor** detects a person approaching the gate.
- If the distance is within a defined range, the **Servo Motor opens the gate**.
- After a few seconds, the gate automatically closes.

### 2. Theft Protection System
- A **Laser beam is projected onto an LDR sensor** using a mirror.
- If the beam is interrupted, it indicates possible unauthorized entry.
- The **buzzer alarm activates** to alert about the intrusion.

### 3. Temperature and Humidity Monitoring
- The **DHT11 sensor** measures the surrounding temperature and humidity.
- The readings are displayed on the **16x2 LCD display in real time**.
